## Reporting tools and other data products to display and visualise bus ticket data

This repository contains code and documentation for a set of reporting
tools and data products designed to display and visualize bus ticket
data. The tools are primarily built using R, quarto and Shiny, allowing
users to interact with the data and gain insights into bus patronage
patterns in the West of England.

### Data Sources

The primary source of data originates from Ticketer bus ticket machines.
